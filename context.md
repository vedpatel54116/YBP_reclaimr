# ReclaimR — Project Context

You are building a production-ready fintech web application called **ReclaimR**.

## Product

ReclaimR is a money recovery app that helps users discover subscriptions, detect recurring bills, cancel unwanted services, negotiate bills, and track savings.

## Important rules

1. Do not copy Rocket Money branding, logo, name, exact UI, or proprietary content. Build an original product inspired by the category.
2. Use a strict black-and-white monochrome design system.
3. Provide two themes:
   - Light theme: white background, black text.
   - Dark theme: black background, white text.
4. Use excellent typography with strong hierarchy.
5. Use only grayscale colors: black, white, neutral grays. No colored buttons, no blue, no green, no red. Use icons, borders, labels, and contrast for states.
6. Build with TypeScript in strict mode.
7. Use clean architecture, reusable components, and production-quality code.
8. Use accessible UI patterns with keyboard navigation, focus states, and high contrast.
9. Use responsive design for mobile, tablet, and desktop.
10. Use realistic empty states, loading states, error states, and success states.
11. Keep the code modular and ready for future scaling.
12. Use environment variables for secrets.
13. Add comments where business logic is important.
14. Prefer type safety, validation, and error handling.
